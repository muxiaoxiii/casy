## 设计规范速查

- **主色**：Slate 石墨蓝 `#3E5C9A`（低饱和，稳重专业）
- **语义色**：红 `#B4554F`=逾期/硬性 · 琥珀 `#B0823A`=等待/催办 · 绿 `#4C8067`=完成 · 紫 `#6C6A9C`=无效轨
- **字体**：Inter（正文/标题）+ SF Mono（时间/数字）
- **规范**：无 emoji、无渐变、线性图标；卡片 8px 圆角 + 1px 边框；信息密度优先
