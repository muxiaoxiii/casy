# Casy 品牌图形（Judicial Docket）

与图标系统同一骨架：双环法务印 + 案卷横线。

## 文件

| 文件 | 用途 |
|------|------|
| `app-icon-512.svg` | 应用图标主稿（macOS / Windows） |
| `app-icon-128.svg` | 小尺寸通用标 |
| `lockup-horizontal.svg` | 横版标版（标 + 字标） |
| `../svg/brand-seal.svg` | 24 网格线性印章（界面角标） |

## 构造

- 外环 / 内环同心，象征法务印鉴
- 中轴竖线 + 两道案卷横线 = Judicial Docket 血统
- 中心蓝点 `#1A4FD6` 仅一处强调
- 16px 时：可去掉内环与中心点，只留外环 + 一道横线

## 色

| 用途 | 色值 |
|------|------|
| 墨底 | `#0C1526` |
| 反白图形 | `#E7EDF5` / `#FFFFFF` |
| 强调点 | `#1A4FD6` |
| 浅底墨线 | `#0C1526` |
