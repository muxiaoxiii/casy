《专利审查指南》创造性判断实务

format_quote

“判断要求保护的发明是否具备创造性，通常应当按照以下三个步骤进行：(1)确定最接近的现有技术；(2)确定发明的区别特征和发明实际解决的技术问题；(3)判断要求保护的发明对本领域的技术人员来说是否显而易见。”

Source: 《专利审查指南》第二部分第三章 3.2.1.1

关于“区别特征”认定的争议点

在针对 Alpha Corp 的无效宣告请求中，对方试图将特征 A 和 B 割裂开来。根据三步法第(2)步，我们需要强调特征 A 与 B 之间存在协同作用（Synergistic Effect），共同解决了散热问题，不能被分别评价。

LIT-2024-012
Nov 05, 2023

显而易见性判断的主观化风险

审查员在第一次审查意见通知书中存在“事后诸葛亮”的倾向。准备答复时，需重点引用指南中关于“避免事后诸葛亮（Hindsight Bias）”的规定，结合本案申请日的客观技术环境进行反驳。
