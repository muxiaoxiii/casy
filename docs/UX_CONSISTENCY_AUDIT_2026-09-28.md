# 全模块交互一致性检查与修订

日期：2026-09-28。范围覆盖整个 Casy 的模块入口与共同行为，不限于编辑器、历史版本、工具策略。本文区分源码修订、浏览器模拟数据验证与待完成的原生业务验收。当前未打包、未发布，不能据此宣布所有业务功能生产就绪。

## 一致性标准

- 导航入口可发现，详情返回有明确目的地；设置深链接可定位指定分类。
- 加载、空数据、筛选无结果、读取失败必须区分；失败提供重试，不能伪装成空列表。
- 保存成功必须以持久化成功为准；失败保留输入；处理中避免重复提交。
- 关闭有修改的表单提示保留；删除和历史恢复说明作用范围。
- 键盘可访问卡片和操作，操作不能仅在鼠标悬停时可见；无文字按钮需要名称。
- 图标表意稳定，避免依赖特殊字体字符；弹窗长内容可滚动，明暗主题使用既有设计变量。

## 历史版本与编辑器

文书历史通过 schema v43 的数据库触发器保存修改前的标题与正文。只在内容变化时留存；恢复采用预期修订号校验，并保留恢复前稿件。恢复不改变关联案件和文书状态。历史从升级后开始，不会凭空补出旧记录；尚无自动清理策略，长期频繁编辑的空间增长应纳入容量测试。

知识历史默认展示完整历史正文；差异比较作为可选辅助，不再作为法律文书的主要找回入口。

块拖拽使用固定六点 SVG 手柄、插入位置线和独立撤销步骤；支持 Alt+Shift+上下方向键及手柄聚焦后的方向键。鼠标拖动与撤销已在页面验证。修复原提交中编辑器 CSS 缺失选择器导致 Vite 无法载入编辑器的问题。

## 工具策略

设置中的工具策略完整列出已禁用工具，提供分类、搜索、启用和写审批设置。持久化成功后才更新运行时。内部 AI 工具策略不等于外部 MCP 授权；外部 MCP 仍使用独立 pending 审批。补齐此前遗漏的读写声明，并修复 `read_document` 对 `draft:`、`knowledge:` 引用的解析。

## 就地操作追加修订

根据实际体验反馈，六点标记扩展为点击/右键可用的块菜单：相邻插入、类型转换、对齐、清除样式、移动、创建副本、复制文本、删除并可撤销。转换与对齐分组为子菜单。文字选区支持浮动样式菜单及右键文字菜单，增加删除线、清除样式和段落设置，保留文书的知识入库入口。菜单统一焦点、上下键导航、Escape、外部点击关闭与视窗边界约束。

案件、卷宗文件、任务、笔记、文书、人员、项目的对象入口接入共用右键菜单；动作复用既有流程，文书删除新增明确确认与失败提示。输入框的系统剪贴板菜单仍保留。卷宗文件菜单已整合进共用组件；画布自身菜单没有被全局拦截，不能宣称所有嵌入式工具的右键体验均已统一。

浏览器追加验证：正文右键、六点点击、块类型子菜单、正文转换一级标题、撤销，以及文字选区浮动菜单应用粗体。均在模拟资料上完成。

## 第二版完善：编辑保护与异常恢复

本版继续在当前源码上迭代，未修改发行版本号、未打包发布。

- 任务详情：关闭按钮、取消、Escape/遮罩关闭、切换编辑对象和路由离开统一检查未保存修改；取消放弃后保留输入。正在保存时阻止关闭与继续修改，异常保留表单并显示失败。
- 文书生命周期：删除其他稿件不再切换当前稿；删除当前稿先处理未完成保存，清理恢复状态，不再因删空列表自动创建空稿。新建前先保存当前稿，避免重复创建。读取草稿列表失败时展示错误，绝不当作空列表自动创建文书；成功保存同步更新最近保存时间。
- 客户：汇总与关联案件请求都补齐异常收尾、错误重试与旧请求失效保护；错误不再同时展示空列表文案，加载/失败时不展示旧案件数。
- 共用右键菜单：支持左右方向键进入/返回子菜单，返回时焦点回到原触发项；子菜单变化重新计算视窗位置，长标题省略；关闭与卸载防止异步遗留监听。

第二版验证结果：74 个测试文件、339 项单元测试通过；TypeScript 检查与生产构建通过；`git diff --check` 通过。

验证包括客户请求失败/重试/竞态、草稿加载失败不误建、删除其他稿不切页、取消删除保留数据、菜单键盘与视窗定位。浏览器模拟数据验证任务未保存关闭提示及“继续编辑”保留输入；不代表原生窗口关闭和真实数据库已完成验收。构建仍有既存大型依赖体积警告。

下一版建议按以下顺序推进：

1. 原生脱敏数据库的升级、重启、自动保存冲突、历史恢复、导出与备份恢复全链路，这是生产验证优先级最高的缺口。
2. 编辑器多块选择/批量操作、长文拖动自动滚动、表格就地菜单，以及全屏写作和小窗口下的操作密度专项验收。
3. 对话框、抽屉和设置表单逐项验证关闭保护；对内嵌画布、源码编辑器保留其适用交互，避免全局强行覆盖。
4. 统一带时区时间戳的显示规则，并用跨日样例检验历史时间、最后保存时间与任务日期；大型依赖延迟加载和长文性能另列专项。
