# Casy UI 优化 · 2026-09-13

面向律师日常办公的产品界面优化，沿用 Vue、Element Plus、现有图标和五套主题。设计取向：低视觉变化（3/10）、低动效（2/10）、较高信息密度（7/10）。导航名称、路由、数据服务和编辑器文档样式继续沿用现有约定。

## 审查与改动

| 范围 | 原问题 | 已落实 |
| --- | --- | --- |
| 全局主题 | 辅助文字偏淡，15 个旧语义变量没有定义，深色按钮对比不足 | 补齐变量别名，提高文字对比，统一主题下的输入、按钮、表格、弹窗、焦点样式 |
| 导航与顶栏 | 中英文层级不清，个人名片只支持鼠标，处理中心按钮没有完整样式 | 中文优先的双语导航，统一按钮，名片改为按钮，补充案件相关子页面选中态 |
| 键盘访问 | 窄窗口导航和搜索弹窗焦点可逸出，导航收起状态播报不准确 | 焦点循环、Escape 关闭、关闭后焦点恢复、背景 inert、跳转主内容入口 |
| 首页 | 指标不可点击，逾期卡片重复强调，空状态没有入口 | 可下钻的三项概览，统一待办列表，轻量风险标记，日历和任务空状态动作 |
| 案件 | 快捷操作与内容标签混排，摘要区域过窄 | 分离快捷工具与内容标签，精简内部标签，列表宽度与窄窗口布局调整 |
| 任务 | 每个透视计数都用不同高饱和底色，逾期行重复铺色 | 中性计数、选中态突出，轻量风险边线，窄窗口工具栏换行 |
| 日历 | 日期与视图硬编码英文，窄窗口切换按钮溢出 | 使用当前语言的日期和翻译字典，中文视图标签，搜索与切换分行，统计纵排 |
| 知识库 | 中等窗口过早切为单面板，短窗口存在固定最小高度，部分按钮深色不适配 | 按工作区宽度选择双栏或三栏，窄窗口保留分区切换，统一工具栏和主题颜色 |
| 文书工坊 | 窄窗口侧栏挤占编辑空间，标签仅支持鼠标 | 列表与编辑独立切换，选中草稿转到编辑区，标签改为原生按钮 |
| 设置与反馈 | 设置导航仅支持鼠标，长表单标签断行，状态颜色不完整 | 原生按钮导航、顶部表单标签、统一空状态、加载和错误播报 |
| 其他列表页面 | 页面宽度、外边距不统一 | 数据看板、客户、项目、实体、提醒和同步页使用共享页面间距 |

## 验证

- `npm run build`：通过，包括 Vue / TypeScript 类型检查。现有大型依赖分块仍产生体积提示。
- `npm run test:unit`：44 个测试文件、215 项测试通过。新增截止事项下钻测试，覆盖逾期、今日、未来、未设日期、已完成和缺少参照日期。
- 浏览器检查：首页、案件、任务、日历、收件箱、知识库、文书工坊、设置、全局搜索。
- 尺寸检查：1280px 桌面与 390px 窄窗口；验证导航焦点循环、Escape、主内容隔离，日历切换、文书列表 / 编辑切换。
- 主题检查：石墨蓝、暖砂大地、日光浅色、日光深色、暗夜深色。主按钮文字、辅助文字、占位文字和风险 / 警告提示的指定颜色组合均达到 WCAG AA 4.5:1。此检查不代表整个产品完成无障碍认证。

浏览器使用现有 Mock 数据。部分后端能力在浏览器中会显示 `browser-mode: no mock`，未据此宣称真实数据库搜索、OCR、文书写入或导出通过原生端验证。法律文档的白色纸面是现有文档主题，与工作台深色主题独立。

## 维护入口

- `src/assets/theme.css`：主题颜色、语义映射、布局变量。
- `src/assets/workspace.css`：共享页面与 Element Plus 控件样式。
- 各 Vue 页面：布局与上下文交互；业务数据仍通过原服务获取。

本次工作建立在工作区已有未提交修改之上，未提交或覆盖其他功能改动。
