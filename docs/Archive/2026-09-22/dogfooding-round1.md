# Dogfooding 第一轮验收清单

> **周期**: 连续 5 个工作日真实使用（方案第 5 周）
> **用法**: 每天结束时在「摩擦记录」表追加一行；一周后汇总评审，P0/P1 项进下一迭代
> **原则**: 只记真实使用中卡住/别扭的地方，不做假想测试

## 三、新增能力抽查（隔日一次）

- [ ] 子任务：展开父任务 → 回车添加 2 个子项 → 完成子项 → 父任务不受影响
- [ ] Review 透视：新任务不再默认出现在下周日回顾列表
- [ ] 系统通知：到点提醒触发系统级通知（非应用内弹窗）
- [ ] AI 工具调用后在 /projects 或任务操作后端留有 audit 记录（如可查）
- [ ] 法律案件照常增改（冻结域回归）：案件详情、时间线、文书入口无损

## 四、真实案件与卷宗专项

- [ ] 新建案件：选择 `民事诉讼+行政诉讼` 路由，保存后案件列表、详情、看板民事/行政视图均能看到该案
- [ ] 新建案件：上传 PDF 卷宗，确认文件先进入案件目录，打开/定位正常，刷新后仍可见
- [ ] PDF 处理：生成可搜索 PDF/PageIndex 后，全局搜索卷宗页内关键词，结果出现文件名和 `[pN]` 页码摘要
- [ ] 知识沉淀：把已处理 PDF 沉淀到知识库，根笔记和 PageIndex 子节点可打开、可搜索、可在编辑器引用
- [ ] 导入进行中案件：从 Excel/飞书导入民事侵权 + 行政裁决/行政诉讼并行案件，检查 `caseRoute`、三条状态、关键日期不丢失
- [ ] 导入更新：同一案件二次导入，空列不覆盖已有状态/日期；新增材料和任务仍挂到正确案件
- [ ] Markdown 草稿：在编辑器插入知识链接/块引用/证据链接，预览无异常，导出 DOCX 后路径和文件大小显示正确
