# 完整离线包与未来双安装包准备

当前只发布完整离线包。OCR、版面分析、embedding、字体、向量引擎及对应许可证及必须交付的源码全部随包提供，不增加首次使用下载流程。

## 已准备的边界

runtime/manifest.json 的 schemaVersion 为 2，delivery 为 full。components 为每个组件列出路径和大小，files 保留逐文件 SHA-256。组件当前全部标记 bundled；旧消费者仍可读取 files。verify-bundle.mjs 验证组件覆盖、不重复、大小一致，以及三组模型完整保留。

SDK 下载归档放到 target/runtime-cache，运行时只保留库、全部嵌套声明和固定版本构建脚本。依赖许可证递归保留；宽松许可白名单包的源码归档移至构建缓存，清单保留版本、来源与校验值。Copyleft／未知许可／无独立声明的依赖及原生组件对应源码继续随包；清理过期的依赖目录。Rust release 使用 thin LTO 和调试信息剥离。

## 未来候选方案（未启用）

两个安装包可分为应用包和离线资源包。资源包含 OCR、layout、embedding、字体以及相应运行库和声明；应用包含界面和业务程序。现有组件清单提供机械分组依据，但不得仅凭目录移动就宣称拆包完成。

启用前还需实现：资源包版本与应用版本的兼容契约；安装路径和显式查找顺序；下载/导入过程的校验、原子安装及失败回滚；签名与升级配合；缺失资源时的能力提示；卸载不误删用户文档；全新离线安装和跨版本升级验证。

模型升级尤其应绑定 embedding 模型标识、向量维度与索引版本，禁止用不同 embedding 模型混写索引。当前 E5 已是 INT8，本轮不改变模型或精度。

## Utopia 借鉴范围

参考 https://github.com/deeplethe/utopia 的双时间图谱、决策记录和来源追溯理念。本轮在现有 SQLite 白板事实与 audit_events 上实现增删改历史、原子修订、内容前后快照、来源文件名与页码，以及历史查看和回到出处。数据库触发器覆盖所有写入路径，纯坐标移动不生成历史；actor=system 表示数据库自动记录，不伪称已识别操作者。

这属于事实修订历史，不等同于完整双时间事实图谱。没有引入 PostgreSQL、自动实体合并或自动法律推理。升级前已发生的修改不能回溯；删除白板后记录仍保存在审计表，但本轮界面从现存白板进入。历史不会恢复已删除的物理原文。

## 钥匙串启动行为

新资料库不查询或自动写入系统钥匙串；数据库继续加密，密钥保存在原有本地密钥文件（Unix 权限 0600）。这不等同于钥匙串独占保护：拥有当前系统账户文件访问能力的程序仍可能读取该文件。已有本地密钥先验证可打开资料库；旧资料库没有可用本地密钥时才回到钥匙串。拒绝访问或密钥不匹配不会生成替代密钥、覆盖资料库。设置 → 备份提供显式钥匙串备份，并读回校验，保留本地副本。启动时的 IMAP 自动凭据迁移已取消，显式迁移命令保留。

启动时的 AI 配置信息读取也改为只读元数据，不先解锁 API 密钥再丢弃。实际调用或测试已配置的 AI 服务时，才读取对应凭据。
