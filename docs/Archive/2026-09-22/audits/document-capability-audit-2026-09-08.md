# 文档识别能力审计与回归矩阵

本审计扩大自 OES/GDS 报告反馈。目标不是修复一个报告就宣告 OCR 完成，而是分清模型定位、内容识别、结构恢复、展示、检索与来源六个环节。真实案件原件只在本地验证目录，不入 Git。

## 已安装模型与实际职责

| 资产 | 职责 | 不能据此声称的能力 |
|---|---|---|
| PP-OCRv6 medium det | 文字区域检测 | 不识别表格单元格或公式结构 |
| PP-OCRv6 medium rec + 字典 | 文字行识别 | 不保证手写、上下标、分式、化学结构准确 |
| PP-DocLayout_plus-L | 20 类版面定位与阅读顺序依据 | 定位到公式／图表不等于识别成 LaTeX／数据点 |
| multilingual E5 base int8 | 已提取文字的检索向量 | 不能识图或补回漏掉的图形 |

版面模型的 20 个标签来自包内 `layout/inference.yml`：paragraph_title、image、text、number、abstract、content、figure_title、formula、table、reference、doc_title、footnote、header、algorithm、footer、seal、chart、formula_number、aside_text、reference_content。标题、图注、页眉页脚等参与阅读顺序；原标签与坐标保留在逐页 layout JSON。

OAR 0.9.2 提供额外的表格结构／单元格、公式、方向与文档预处理能力，但对应预测器需要各自权重。安装包未含 SLANet/单元格模型、PP-FormulaNet/UniMERNet、方向分类／去弯曲权重。不能仅因为 SDK 有 API 就宣布这些能力可用，也不把语言模型猜测当作检测报告原文。

本地源码依据：OAR `examples/formula_recognition.rs`、`examples/table_structure_recognition.rs`、`src/oarocr/table_analyzer.rs`；上游：[OAR](https://github.com/greatv/oar-ocr)、[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)。固定版本与模型下载校验记录见 `tools/casy-doc-engine/install-models.mjs`。

## 输出合同与验收矩阵

| 类型 | 当前输出 | 验证／边界 |
|---|---|---|
| 普通中英文、数值、比较符 | OCR 文字 + 区域坐标 | 字符错误仍可能出现；保留原始 OCR JSON，不自动改写实验值 |
| 多栏正文、居中标题、页眉页脚 | 基于版面块的阅读顺序 | 通用多栏与续页标题测试；复杂穿插版面仍需原页核对 |
| 有线、轻微倾斜、合并单元格表格 | HTML table + rowspan/colspan + 逐格来源 | OES 80 数值、20 行名、4 样品列；GDS 4 列元数据；淡灰细线通用测试 |
| 无边框、断裂或不确定结构表格 | 被定位到时保留表格原图 + 核对提示 + 辅助 OCR | 尚无可靠的无边框结构恢复，不能生成假表格 |
| 曲线图、图片、流程图 | 模型定位区域的无损 PNG，嵌入 Markdown | GDS 8 张曲线图；不声称提取曲线采样数据或流程图语义 |
| 公式 | 被定位到时保留原图，单独标注“未转换为 LaTeX” | GDS 两个公式区域；通用原图像素保真、文字折叠、校订保图测试；漏检的公式仍不能保证被分离 |
| 印章 | 被定位到时保留印章原图 | 印文 OCR 仅作辅助，不判断真实性 |
| 手写／签名 | 原文档对照页保留，OCR 结果可核对 | 无专门手写模型，不能保证转写准确 |
| 90/180 度倒置、弯曲、透视、低分辨率 | 未宣告可自动校正 | 当前网格小角度校正不能替代方向／去弯曲模型 |
| 可搜索 PDF | 原页视觉内容 + 隐藏文字层 | 原件哈希不变；伪造旧文字层不会成为新 OCR 权威来源 |
| Markdown 导出和预览 | 原图内嵌，原文标签转义，预览消毒 | 单文件搬移不丢图；脚本属性移除；图内文字折叠显示 |
| 来源与校订 | 唯一区域标记、坐标映射，校订保留表格／图形 | 重复／缺失标记降级，不能编造坐标；旧识别可重新处理并保留旧版 |
| 知识库 | 图文可预览，文字可检索 | 图像 Base64 不进入向量分块；保留原始字符串偏移，避免索引图像乱码 |

## 本轮系统性修复

1. 从“只消费 table 标签”扩展为消费 chart/image/formula/seal 等视觉类别。保留精确裁切坐标，去除高度重叠的重复区域。每页输出 visuals JSON，明确 `semanticExtraction: false`。
2. 图形以来源像素保存，不通过 OCR 重绘曲线，不通过语义补写数值；图注仍按正常文字位置呈现，图内文字可展开查看。
3. 表格识别区别“查找边线”的宽容搜索和“确认单元格边界”的窄带检验，兼顾淡线与文字笔画干扰。不能只调深色阈值，否则把正文笔画误当边界。
4. 图文导出、消毒、校订与知识库索引一并回归，不只验 OCR 引擎输出。

## 后续真正需要新增能力的领域

公式 LaTeX、无边框表格、复杂手写与扫描方向／弯曲恢复仍有能力缺口。需要选择并验证专用模型，评估体积、跨平台推理、许可证与真实样本准确率后再纳入完整包。当前不额外增加未经验证权重，不把原图保留标成“结构识别成功”。

这份矩阵是持续验收清单，并非“所有文档已识别正确”的证明。扩大真实语料覆盖时必须逐类记录准确率与失败案例；单一样本通过、关键词存在、测试数量都不能替代版面与数值核对。
