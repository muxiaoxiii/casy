# 知识库全文向量索引与检索验收

## 变更

原知识库向量路径硬编码 Ollama 地址和模型，只取正文前 512 字，也没有在正文或模型变化后失效。批量接口返回的是尝试数量，无法说明索引是否完成。

现在复用 AI 多配置的接口、协议和原生钥匙串凭据，单独设置向量模型与分段长度。支持 OpenAI 兼容 `/embeddings` 和 Ollama `/api/embed`；测试连接使用已保存配置和合成文本。回环地址直连，远程地址保留系统代理行为，请求不跟随重定向。

Schema v28 新增持久任务和分段向量表，按完整正文建立重叠分段，每批最多 8 段。只有全部分段完成、正文和配置版本仍一致时才发布索引。失败、取消、中断和正文变化后的分段不会用于检索。相同正文与配置去重，丢失分段时允许修复；可以取消、重试或主动重建。配置指纹包含接口身份、协议、地址、向量模型和分段长度，不包含密钥。

中文关键词检索使用 trigram FTS、中文分词和短词回退。混合检索合并关键词与语义排名，返回实际命中段落。接口失败、超时、配置变化或向量维数不符时保留关键词结果并显示原因。未配置、没有当前索引或选择关键词模式时不发送向量请求。数据库扫描在阻塞工作线程执行，排名和结果读取使用同一数据库快照。

迁移测试发现旧全文索引的更新触发器会在更新时间的嵌套更新中重复操作 FTS，修改标签可触发 SQLite `database disk image is malformed`。v28 限制为实际标题、正文或标签变化时更新，并在迁移时重建旧 FTS。升级、编辑、删除和重复初始化均已验证。

界面新增可在窄屏打开的知识库检索抽屉，包含关键词/混合模式、实际片段、空结果、错误状态和索引队列。检索结果按 ID 重新读取正文，因此可打开初始 2,000 条列表之外的笔记。

## 使用边界

- 本批未访问飞书接口、未修改飞书数据、未向外部 AI 发送真实案件材料；未更新已安装发行版或正式案件库。
- 合成向量用于验证真实请求、持久化与检索流程，不能证明实际模型的法律语义准确率。真实模型召回率、延迟和大规模知识库性能仍须单独验收。
- 向量检索当前顺序扫描匹配模型的分段，尚未引入近邻索引。笔记单篇正文上限 64 MiB；整批入队遇到超限笔记会回滚并显示错误。
- 取消会立即阻止结果发布，但已发出的 HTTP 请求可能继续至完成或 30 秒超时；语义查询单独限时 5 秒。
- 分段请求复用既有 AI 调用额度。既有计数仍在进程内，重启后重置，不应视为持久计费统计。
- 知识库初始列表仍整体读取最多 2,000 条正文；检索结果已能独立打开，但大库列表分页与大笔记编辑体验仍需后续处理。

## 复现

```sh
npm run build
npx vitest run --config vitest.config.ts
cd src-tauri
cargo test --lib --tests
cargo build --example knowledge_local_bridge
cd ..
CASY_QA_URL=http://127.0.0.1:1422/ CASY_QA_DIR=/path/to/private-artifacts CASY_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node tests/e2e/knowledge-index-local.mjs
```

独立导出的开发服务器应设置独立 Vite `cacheDir`，避免与工作区共享依赖优化缓存。
