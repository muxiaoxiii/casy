# 事实白板集成修复 Work Plan

> 状态更新：用户实测后指出产品定位仍不成立。暂停本方案的安装包交付；本文件仅保留已进行的接线修复记录，不能视为白板功能验收通过。后续设计见 [案情梳理重新设计](case-analysis-redesign-work-plan-2026-09-08.md)。已做的数据一致性、历史保护、原生导出等修复保留，是否继续以 Excalidraw 作为主要界面不再预设。

## 用户反馈与审计结论

用户要求完善既有白板。当前实现将事实表与 Excalidraw 场景分开，事实仅通过手动快照上板：新建节点不可见、画布修订不回写、旧连线未传入。引用仅创建绘图矩形，不成为事实记录。导出使用 DOM download，在桌面 WebView 中无落盘保障。引用弹窗缺少统一表单布局，未充分配置编辑器默认值。旧测试使用空 Excalidraw API mock，没有覆盖这些交互，不能作为功能验收证明。

## 实施决策

- 保留既有案件 / 白板路由、事实表、事实审计、截图、已有绘图及版本历史；Excalidraw 作为绘图组件。界面沿用 Casy / Element Plus 的字体、颜色和布局，不另造产品风格。
- 统一一个工作区：事实列表与详情和画布互相定位，新增立即在视口出现；事实文本、批注、位置、来源以及事实间的绑定箭头通过一次事务同步保存。事实记录不再是另外一张孤立画布。
- 所有已有事实自动接入；旧快照、旧引用和连线迁移时保留用户文本及自由绘图。截图继续随场景保存。自由文字与图形不强行变成法律事实。
- 新增知识库来源字段；引用面板显示来源、类型、案件、内容预览、可选页码和确认状态。新引用通过后端验证，拒绝无效来源与跨白板写入；来源文件的案件可不同，导航使用真实来源案件。
- 场景修订号和事实内容摘要共同防止并发覆盖；保存失败保持未保存状态并阻止切换白板 / 离开。撤销 / 重做与删除恢复均纳入验证。
- 使用原生保存对话框和后端原子文件写入导出 PNG、SVG、可编辑 .excalidraw；取消不报成功，失败明确提示，长图限制输出尺寸。禁用未接入的上游在线菜单与默认下载入口。
- 默认使用易读字体、实线、低粗糙度、正常字号与选择工具；跟随 Casy 深浅主题，默认导出浅色背景，字体自托管，关闭在线 AI / 网页嵌入 / 在线素材库。

## 验证与交付

1. 真实组件交互测试：创建、编辑、引用、移动、绑定连线、删除与撤销、保存重开、截图、来源跳转。
2. 原生命令测试：事实和场景原子一致、来源验证、冲突保护、旧白板迁移、导出真实文件签名及失败路径；使用隔离资料库。
3. CUA 在独立应用中实机核验，不能仅凭 mock 测试宣告完成。正式 Casy 中正在运行的转换不受干扰。
4. 前后端检查、完整 ARM Mac 包构建与实际 DMG 验证；记录 walkthrough 中的真实证据和限制，不替换正式安装或正式案件数据。
