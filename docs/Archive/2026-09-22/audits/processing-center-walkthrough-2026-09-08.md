# 处理中心实施复核

实施前计划：[work plan](processing-center-work-plan-2026-09-08.md)。

## 用户可见行为

顶部“处理中心”常驻。关闭抽屉、切换案件或收起转换弹窗不会停止任务，入口显示运行与排队数量。抽屉统一显示任务名称、所属案件、阶段、页数 / 分段、错误、创建与更新时间。可回到文件或知识条目；有输出文件时可在文件管理器定位。OCR 和知识队列按原有后端能力提供取消。

可按全部、处理中、失败 / 需重建、等待触发、已结束筛选。后端按全库统计、每页 30 条返回，能翻到全部历史；不是旧知识状态接口的最近 100 项，也不受当前案件限制。历史里的失败记录不会因一次重试成功而被删除。任务明细和后台服务分开计数；等待下一次检查不会冒充运行中的作业。

“文件转换”在开始前登记整批任务，因此尚未轮到的文件也可见；新增“收起到后台”。停止后续转换会将尚未开始的记录取消。每次重试建立新记录，保留上次结果。退出后无法接续的单独转换标记中断；文档持久队列中尚未开始的任务保留，已中断任务明确失败。

文件详情按钮改为“开始识别并生成可搜索 PDF”。添加 PDF 本身不等于进入 OCR 队列；可以手动启动，或在设置中启用目录自动识别。原件只读，可搜索 PDF 和 Markdown 是衍生文件。

## 接线范围与依据

| 来源 | 处理中心显示方式 |
|---|---|
| 全部案件文档队列 | 原持久队列表；页数、OCR、PDF 整理、后续文档索引阶段 |
| 知识索引队列 | 原队列表；分段进度；模型配置变化后的过期索引标为需重建 |
| 单独文件转换 | 新持久活动表；整批排队、处理结果、输出路径与错误 |
| 目录自动同步 | 最近检查状态，登记 / 排队 / 知识同步 / 更名数量；未启用明确显示 |
| 向量检索缓存 | 检查 / 同步与等待状态，失败可见 |
| 飞书与 WebDAV | 实际同步活动历史；飞书自动推送另显示启用 / 等待状态 |
| 收件箱目录监听 | 服务状态与逐次导入历史 |
| 邮件 | 监听状态、异常与实际收取活动历史 |
| 期限与开庭提醒 | 规则引擎最近检查；提醒作业历史和未来交付时间 |
| 日历 | 提醒持久交付状态及异步同步活动 |
| 定时工作 | 每日期限重算、早报、周报、决策复核、数据蒸馏、关联洞察的等待计划和运行历史 |
| AI | 对话处理活动与 AI 调用审计记录；不保存提示词或响应正文到处理中心 |
| 数据库备份 | 创建与校验活动历史 |
| 本地 MCP 服务 | 监听 / 未启用 / 启动失败状态 |

周期轮询服务保存最近状态，避免每 3 秒 / 10 秒的空检查制造无限历史；具体任务保留运行历史。主任务和内部 AI / 日历调用可能分别出现，计数单位是活动项而非文件数。新增后台流程应接入 `processing::tracked` / `Activity` / `service`，或向聚合接口登记它的持久队列；普通即时读取接口不会被当作后台任务刷屏。

## 数据与恢复

Schema 38 新增 `processing_activities`，同时给文档任务补充独立索引状态与错误。旧记录只从最新文件状态回填，回填排在历史可选字段补齐之后；迁移重复执行不会重复建表或覆盖旧识别版本。

原实现先把 OCR 作业写为完成，再调用 PageIndex，造成处理中状态提前消失。现在索引阶段仍显示处理中，失败保留已完成的 OCR 输出并单独显示索引错误。只有重新运行 OCR 才会创建新识别版本。

处理中心复用现有数据库，不增加钥匙串探测、不改变 OCR 导入开关、不启用任何云端同步或外部模型。查询在一个读事务内完成计数和分页。前端不重叠轮询，关闭抽屉时每 5 秒更新入口，展开时每 2 秒更新；筛选变更丢弃旧响应，卸载清理定时器，读取失败保留旧快照并明确告知未刷新。
