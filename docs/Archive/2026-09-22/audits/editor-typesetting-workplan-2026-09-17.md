# 编辑与排版一体化 Workplan

日期：2026-09-17。依据：[研究报告](markdown-editor-reference-study-2026-09-17.md)。本轮在已有工作区上增量实施，不重置已有修改。

## 目标与验收

按“内容保真 → 局部编辑与预览 → 真实 A4 排版”的顺序实施。保留 TipTap 与既有文书/知识库工作流。性能用实测记录，不承诺 0ms 编译；未知内容不静默丢弃，导出失败不覆盖文件。

## 第一阶段：内容保真

- [x] 为数学公式、脚注引用/定义建立可持久化节点和原始源码属性，解析优先于普通 Markdown 强调/链接。
- [x] 支持 H1–H6；表格对齐、列宽和合并跨度使用显式安全属性往返，不放开任意 CSS。
- [x] 为未修改的顶层 Markdown 块复用原始源码；修改块用语义序列化回写。数学、脚注及未知原文块保留源标记，不经普通文本转义。
- [x] 将研究样例转为保真断言：追加无关段落、修改目标节点、撤销、保存重开均覆盖。

## 第二阶段：公式与图表交互

- [x] 专用 TipTap NodeView：显示结果、局部编辑源码、保存/取消、输入法组合期间不抢快捷键。
- [x] 本地公式/图表渲染；延迟到可见区域、丢弃过期结果、清理资源、预留高度并保护滚动位置。
- [x] 工具栏/插入入口与知识库、文书共用；不另建与 ProseMirror 脱节的撤销历史。
- [x] 测试调度、旧结果失效、节点保存往返、组合输入事件边界。

## 第三阶段：Typst 与 A4 并排预览

- [x] Rust 嵌入 Typst/typst-pdf，直接从统一编辑文档生成安全 Typst 内容，固定随包字体；支持常见节点、公式、脚注、表格、图片与引用。
- [x] 共享预览/导出编译路径，明确处理缺图、缺字、未知节点与编译诊断。
- [x] A4 版式参数：页边距/装订边、首行缩进、文书标题/案号页眉与页码页脚；预览与导出使用同一版式。
- [x] 文书工坊并排预览、异步防抖/过期请求保护；编辑块与排版结果双向定位。位置映射以文档节点为依据，不用滚动百分比冒充。
- [x] 所有 IPC 契约、前端服务与导出按钮接入。现有 Word 导出对新增节点要支持或明确拒绝，禁止静默丢失。

## 验证与交付

- [x] 定向前端回归、类型检查、Rust 排版测试（中文可搜索、分页、表格、公式、脚注及未知节点）。
- [x] 适当的完整前端测试/构建、Rust 编译检查；对失败明确区分本轮问题与基线问题。
- [x] 实际界面检查；系统输入法/不同平台未实测的项目如实列为边界。
- [x] 写 walkthrough，记录实现、命令、结果、性能口径与剩余限制。

设计实现允许按实际库 API 调整，但不能用静态 HTML 纸张或截图代替真实 Typst 排版，也不能用测试通过掩盖不支持的语法。若依赖或环境确实阻断，则完成不受影响部分并记录具体证据。


## 实施结果与边界

已完成三阶段首版，验证过程和证据见 [Walkthrough](editor-typesetting-walkthrough-2026-09-17.md)。勾选表示本轮约定范围完成，不代表全部 Markdown 方言、全部 LaTeX/Mermaid 语法或所有平台均获支持。

- 保真以未修改、可映射的顶层块为单位；普通链接定义独立保留，可能移到文末；改动块会规范化，不能承诺整个文件逐字节不变。
- 双向定位为顶层文档块与真实页坐标；长表格/长列表定位起始页，尚非字符级位置映射。
- Word 对新增公式/脚注节点明确报错，Markdown 与 PDF 已支持本轮语义节点。
- 真实界面验收为 macOS Chrome + 本地 Rust 命令桥。已人工检查截图及 PDF 栅格化结果；系统 IME、Tauri WebKit 与 Windows 尚未实测。
- 全量 Rust 测试有既有日期断言失败；本轮排版定向测试通过。MCP 测试的沙箱端口失败在允许本机端口后全部通过。
