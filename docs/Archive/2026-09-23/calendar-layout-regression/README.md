# 日历布局回归检查 · 2026-09-23

本轮仅修改前端源码并提交本地 Git，未编译原生应用、未打包，既有 0.1.3 DMG 不包含这些修复。未使用用户资料库，也未调用 AI 或远程服务。

## 发现与修复

- 时间线日期标签、时间戳依赖绝对定位，休班日无任务时行高塌陷、日期和标记叠压。改为正常网格流，日期与卡片各自占位；休班名称、来源、无排期说明放在内容区。
- 时间线使用展示类型判断编辑入口，普通日程被当成任务，庭审丢失案件 ID，任务日期/备注等原始字段丢失。保留原始对象和来源类别，点击或键盘激活卡片打开正确编辑器/案件标签页；键值加入类型前缀。
- 案件筛选绑定 label 点击，可能被原生 checkbox 的转发点击重复触发。改为 input change，支持键盘和全部案件的取消选择。
- 周视图日期/全天行使用 54px 时间栏，实际时间网格为 48px。统一栏宽，休班标记移到日期下方并预留位置；全天事项长案件名截断并提供完整悬停提示，列表限制高度。
- 日视图长跨日任务横向溢出。任务名可换行、日期和操作可换行，完成按钮禁止压缩；排期长任务的日期区间保持完整。
- 月/周网格使用 minmax(0, 1fr)，按日历容器宽度收起侧栏；年视图日期与休班标记分开占位，月份列数按容器宽度调整。
