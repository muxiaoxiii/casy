# 横向甘特任务排期验证

日期：2026-09-23。源码版本：0.1.3，数据库 schema v42。本轮仅完成甘特排期这一后续计划项；未打包、安装或上传，历史 DMG 不包含本次改动。

## 实现

- 日历「排期」内新增横向甘特，保留负荷列表和日→周→月→年→时间线→排期顺序。按主要关联案件分组，支持搜索、已完成筛选和每页 40 项。
- 日尺度显示 28 天，周尺度显示 84 天。休息底纹取主题色，法定与个人休/班标记区分显示；任务截止菱形、案件期限和庭审为固定节点。
- 拖动、两端拉伸、方向键（Shift 七天）或日期表单均先进入确认。取消手势不写入，保存失败保留原条及草稿；修订冲突须显式载入最新计划。
- `task_plans` 独立保存起止与修订号，取消计划保留空值和修订号；不改写任务 start_date/due_date/deadline，更不修改法定期限。旧开始日仅作为新建计划的单日建议值。
- 服务端校验完整日期、顺序、最长 3660 天及任务状态；立即事务完成版本比较、计划写入和任务审计，失败整体回滚。软删除隐藏计划，恢复任务后重新显示。
- 保存前按完整日期范围查询休班及案件期限，查询失败阻止提交。提示休息日、其他计划日期重叠和跨越案件期限。个人安排仅影响工作安排，不参与法定期限推算。
- 独立计划联动日/周/月、负荷列表、时间线、年热力图及休息日提醒；取消后不会重新使用旧跨度，实际截止日仍保留其独立提醒。

## 边界与后续

每页最多 40 项；分组采用任务的主要关联案件。日期重叠只是工作量核对提示，尚无工时容量、依赖关系或自动资源调度。提示不自动阻止休息日排期或跨期限安排，由用户确认。
