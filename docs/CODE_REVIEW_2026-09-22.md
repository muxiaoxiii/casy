## 新增发现

**WebDAV 旧路径存在密钥泄露与恢复一致性风险。** 旧实现上传 `.key`，先覆盖本地密钥再验证数据库，并直接替换活动库。0.1.3 只上传校验过的加密快照；不读取远端密钥；密钥不匹配立即拒绝，合法恢复复用维护锁、恢复前备份和校验。历史服务器上的密钥文件不会自动删除。数据库快照不含附件，新设备优先使用完整加密备份。

**发布质量仍有明确边界。** 本地 `cargo clippy --lib --tests` 已清零（2026-09-23）：公式字符串解析/旧 PDF 入口保留并标注用途，机械 Clippy 与死代码警告已处理；前端仍存在大 chunk 提示（elk/巨型 chunk），CI 的远端 Clippy/audit 与公证不在本轮通过结论内。真实第三方服务、100/500 页资源压力、断电恢复和公证不在本轮通过结论内。

审阅证据和回归结果见 [0.1.3 验收记录](RELEASE_0.1.3.md)，后续按 [更新计划](UPDATE_PLAN.md) 执行。

## 2026-09-23 修订审阅

- 主题回归：全局 `:root` 和复用旧主题 ID 覆盖原调色板。已将卷宗主题隔离，恢复原 ID；CSS 层叠和八套实算颜色检查通过，黄宣纸纹理只作用于应用。
- WebDAV 完整备份复用已校验的可迁移加密格式，不复用旧裸数据库同步。远程临时文件完成后 MOVE；失败保留当前本地数据。独立备份密码不持久化，恢复先做本地保护备份；系统钥匙串凭据不包含在档案内。仍需真实服务器协议、断网、磁盘满和多设备冲突验收。
- 节假日处理有真实事务写入，但旧解析器混合分句会误判，且日历缺少逐日可见反馈。修正分句、核对 JSON 入库、原子回执及逐日标记；已处理收件详情读取持久化回执，零变更明确展示。AI 只在显式按钮触发时调用，失败不归档。复杂/省略日期仍须人工核对，未验证用户此次原通知。
- 年视图按任务日期统计，处理闰年、跨年、跨日和重复任务，每任务最多迭代 366 天；未排期任务不计入。浏览器预览证明交互和主题渲染，持久化由独立后端测试验证。

- 个人调休与法定日历隔离：新增独立设置验证与 UI 入口，六种视图共享来源标记，跨年区间加载相邻年份。法律期限计算继续只读法定日历；集成测试验证同日双来源、非法日期不覆盖已有设置与移除个人安排后法定数据保留。

- 休息前提醒已接入后台引擎及通知查询，覆盖连续休息区间、未完成任务/期限、独立日程与待开庭；排除已完成、已开庭、取消项，任务与时间块同一标识去重。失败只记录日志，不阻断既有期限提醒。应用关闭时尚无系统后台唤醒保证。
