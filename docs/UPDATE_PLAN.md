# 后续更新计划

更新：2026-09-22，基于 0.1.3 生产验证版。原 0.1.2 待执行计划保留于 [Archive](Archive/2026-09-22/pre-0.1.3/docs/UPDATE_PLAN.md)。本轮完成情况见[审阅处置](CODE_REVIEW_2026-09-22.md)。

| 优先级 | 下一步 | 验收要求 |
| --- | --- | --- |
| P1 | 端到端有界内存文档处理（R-02） | 页 IR/图像先落盘，IPC 返回路径与摘要；100/500 页扫描、单页巨图和复杂矢量测 RSS/磁盘；不随页数线性累积 |
| P1 | 长任务恢复与结果查询（R-06） | 持久化完整产物清单与结果；窗口断开后可查询；幂等重试、重启中断与恢复、磁盘满故障注入 |
| P1 | 真实工作流验收 | 使用脱敏案件覆盖收件→案件→卷宗 OCR→来源引用→文书→备份恢复；逐项由使用者确认业务正确性 |
| P2 | WebDAV 协议升级 | 端到端加密档案、附件清单、条件提交与版本冲突协议；双设备/真实服务故障矩阵，不能用 ETag 相同推断本地无修改 |
| P2 | OCR 质量集 | 密集双栏、跨页表、低清、印章、公式、多语种；公开基准与人工对照，分别统计文本/布局/结构错误 |
| P2 | 发布门禁后续 | 运行远端 CI、清理既有 Clippy 债务、依赖漏洞审计；Developer ID/公证、正式条款和跨设备安装测试 |
| P3 | 编辑器/预览的大文件交互 | 协调 16 MiB 全文读取、40 MiB 编辑器导出、128 MiB 校订边界，设计分段入口；不简单扩大常量 |
| P3 | 分发与平台 | 完整 Windows/Linux 运行时、真实机器验收；模型拆包、升级兼容与回滚 |
| P3 | 产品补全 | 截图、自动剪贴板监听、语音转写和占位批处理逐项实现；保持未实现项明确提示 |

本轮不宣称任意大小文件、断点续跑、所有网络服务或正式公证已经完成。后续每项以独立提交、故障测试和可复核证据关闭；过程日志进入 Archive，现行根文档只保留最新结论。
