# Casy 任务生命周期验收

## 本批修复

- 任务编辑写入 `edited` 审计事件，但旧约束拒绝这个值，导致实际保存回滚。迁移 30 保留历史事件并补齐约束。
- 完成和切换状态共用事务内的重复实例、共享案件引用和顺序步骤处理。重复实例生成失败会回滚完成，不再静默丢掉后续任务。
- 每个来源任务只生成一个有效后继。撤销完成会收回未经修改的后继；已经编辑或被引用的后继保留，重新完成不会继续复制。
- 修复月末、十二月跨年与工作日重复日期。后继保留时间、父任务、知识引用及多对多案件关系，跟进和回顾日期随周期移动。仅有计划日期的任务不会新增截止日。
- “稍后”只改变计划日期；截止日期与截止时间保持不变。周末使用周六，非法日期和未知选项拒绝保存。
- 任务列表读回截止时间和时间段，父任务字段对齐；新建时空案件、空领域归为 NULL，恢复删除保留时间段。
- 顺序步骤按同案件、同父任务分组。完成、删除、恢复和撤销会重新计算后续步骤；未分组的个人任务不会相互锁定。
- 表单增加任务类型、开始安排、截止时间、重复、等待对象、跟进和回顾日期。保存失败保留输入，保存中防止重复提交。待回顾按钮实际写入已回顾日期。
- 完成与改期可撤销，撤销失败保留操作供重试。撤销删除使用不可变字段快照。任务列表和徽标采用一致的筛选条件，推迟不会隐藏已经到期的任务。
- 窄屏表单限制在视口内；顶部搜索换行，保留新建按钮。完成控件支持键盘和复选框语义。截止时间不再被错误展示为“截止时间加预估工时”的安排区间。
