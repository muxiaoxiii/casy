# 案卷、知识库与引用编辑

## 检索选型

建议默认保留 SQLite 全文检索和本地页码目录树；语义检索可选本地 BGE-M3，另以 Qwen3-Embedding-0.6B 做真实法律材料对照评测。未进行两者在本案材料上的质量排名，也未自动下载或配置向量服务。

- BGE-M3：MIT，100 多种语言，1024 维，最长 8192 tokens；适合中英德法日混合资料。Casy 现有 Ollama / OpenAI-compatible embedding 协议可接入；目前使用 dense embedding，不宣称接入其 sparse / ColBERT 输出。
- Qwen3-Embedding-0.6B：Apache-2.0，100 多种语言，32K 上下文，32 至 1024 维；可作为本地服务的备选。其检索指令和运行效率需要独立评测，不能把 8B 的榜单成绩当作 0.6B 的质量保证。
- 本地 embedding 无 API token 账单，但仍消耗计算资源。远程 embedding 通常按输入计费，与聊天模型的推理、生成计费不同。当前分段有重叠；更换模型或正文后按配置与正文哈希重新排队，未变内容复用索引。自动索引开关关闭时不会自动请求向量服务。

核对来源：
- https://huggingface.co/BAAI/bge-m3
- https://huggingface.co/Qwen/Qwen3-Embedding-0.6B
- https://github.com/VectifyAI/PageIndex/tree/ae304b01454d3f67b1fbc50c06703af45aa45427

PageIndex 上游包含树索引与 LLM 推理检索。当前上游 Flash 能从文档布局提取树结构，摘要和细化仍使用模型，检索过程也使用 LLM。所谓 local mode 并不等于无模型调用或没有远程 API。Casy 当前 `ai/page_index.rs` 是受其启发的本地 Markdown 标题/页码树，并没有把上游整个代理流程嵌入产品。全文检索和树构建不消耗生成式 token；AI 问答是另一个显式入口。

## MinerU-Popo

核对版本：`97d560172361e772b3d079ce9eac35796b998782`，MIT。
https://github.com/opendatalab/MinerU-Popo/tree/97d560172361e772b3d079ce9eac35796b998782

它是 4B 文档后处理模型及 Python 流程，任务包括跨页正文/表格截断、标题层级、图文关联。表格推理依赖前级解析的结构化单元格；Casy 当前仅有 OCR 区域，不能据此宣称完整跨页表格重建。

本轮按 `post_processing/inference.py` 中 `merge_rules/filter_contd` 的思路移植了文本候选筛选：句末标点、引用结束符、列表/标题边界、相邻页几何、重复页眉页脚。结果保留两页区域坐标，界面可打开两页对照。候选不会改写原文、自动删除断词或强行合并表格。完整 MIT 文本随运行时分发。未引入 4B 模型、vLLM、远程摘要或整页模型请求。

## 本轮实现

- 启动引导从三步缩为一页，保留称呼、执业领域、工作时段。删去无消费方的常用案件类型、未接到真实提醒通道的重复配置；允许跳过，时间范围验证后保存。
- MarkText 法律/专利主题适配富文本、块编辑器和 Markdown 预览。四层引用按红/绿/蓝/赭区分；最外层按最大深度着色，内部不重复缩进或画边框。标准主题可切回，四个来源名称可配置。混合层级外层引用拒绝一次性改深度，防止丢失来源结构。
- 知识库支持多案件筛选，直接列出真实文件及当前 Markdown 正文，待处理文件可手动提取。知识快照可独立编辑；重新 OCR 生成独立版本，不覆盖人工笔记。
- 六项独立自动化：目录登记、OCR/文本提取、知识快照、向量索引、案号前缀、正文标题命名。均默认关闭，保存后生效。
- 后台每 10 秒核对已绑定案件目录，连续两次大小和修改时间稳定后处理。跳过临时、隐藏文件和符号链接；利用文件哈希及稳定 ID 识别无歧义的外部改名。文件失踪保留记录，手动移除不自动复活；失败、取消的同版本 OCR 不无限重试，保留显式重试入口。
- 重命名复用既有防覆盖流程，当前 Markdown 笔记中的本地文件链接同步改写。知识引用和 PDF 页码仍使用稳定文件 ID。历史版本中的任意 HTML 文件路径不在本次改写范围。
- 正文标题命名只使用明确 Markdown 标题或文首可识别的法律文书标题，没有可靠标题则保留名称；不调用生成式模型推测标题。
- 案卷界面接收同步更新事件；知识正文列表轮询最新任务，原件哈希变化时拒绝把旧正文当成当前版本。

## 边界

自动扫描仅覆盖已绑定的案件目录；文件移失保留记录。大小与修改时间都被刻意保持不变的内容更改可能被元数据缓存漏过；外部改名只在同案件内、同哈希且候选唯一时保持身份。新向量模型未随本轮自动下载配置，也没有生成式模型跨页表格重建。当前产物仅验证 macOS Apple Silicon，采用 ad-hoc 签名，尚无 Developer ID 签名及 Apple 公证，不能称为已公证的公开发行版。
