# 本地文档 OCR 验证（2026-09-06）

## 本批结果

- 手动 PDF、图片和自动 OCR 均进入同一个持久队列，移除 Tesseract 进程调用、Cargo 依赖及前端安装提示。
- 原生队列支持排队/运行中取消，按新任务 ID 重试，检查排队后的源文件变更。取消后的进程不能把结果写入后续任务。
- 完成时校验源文件 SHA-256、任务目录、页码、坐标和置信度、落盘 JSON/Markdown 一致性，回填 ocr_text，执行自动归类并构建 PageIndex。
- 同一秒内完成多个版本时，搜索和页级读取按任务顺序选取最新完成版本，避免旧结果混入。
- 文档引擎按页渲染和释放图像。坐标识别最长边 2400px，生成模型最长边 1280px，ONNX 两线程共享线程池并关闭空闲自旋。
- 可提取的原生文字页支持直接提取。检测到大面积图片时保守使用 OCR；多帧图片明确拒绝，避免静默遗漏后续帧。
- 模型输出触及 token 上限即失败；原生进程每秒同步页进度，单页 15 分钟无推进即终止，并限制输出缓冲。
- 文件详情在窄窗口改为纵向布局，修复原先直接隐藏详情导致的 OCR 操作不可达。全文弹窗宽度适配手机，工具栏不越界。

## 真实模型证据

PDF 渲染使用 Poppler，模型安装脚本使用 Node.js。没有 Python 模型服务或外部推理请求。
