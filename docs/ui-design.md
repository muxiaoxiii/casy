# Casy UI 设计方案

> 版本: 1.0 | 日期: 2026-07-31
> 目标：定义一套可交给 AI 生成 UI 的完整设计规范

---

## 一、设计原则

### 1.1 核心理念

**法律工具，不是社交产品。** 信息密度优先，操作效率至上。

| 原则 | 说明 |
|------|------|
| 信息密度高 | 一屏看到最多有效信息，不浪费空间在装饰上 |
| 操作路径短 | 最常用的操作 1-2 次点击完成 |
| 视觉层次清晰 | 用字号/颜色/间距区分优先级，不用边框堆砌 |
| 状态一目了然 | 案件状态、期限紧迫度、任务优先级——扫一眼就知道 |
| 克制用色 | 主色 1 个 + 中性灰阶 + 状态色（红/黄/绿） |

### 1.2 参考方向

| 参考对象 | 学什么 |
|----------|--------|
| Linear | 左侧窄导航 + 内容区最大化 + 键盘快捷键 |
| Notion | 信息块组织 + 折叠/展开 + 拖拽 |
| Obsidian | 双栏布局 + 侧边面板 + 知识关联 |

**不参考**：管理后台模板（Element Plus Admin）、仪表盘模板（数据可视化为主）

## 二、设计系统

### 2.1 色彩

```
主色（品牌色）：#2563EB（蓝色，专业/信任感）
主色 hover：    #1D4ED8
主色 light：   #EFF6FF（选中态背景）

中性灰阶：
  --gray-50:  #F9FAFB（页面背景）
  --gray-100: #F3F4F6（卡片背景）
  --gray-200: #E5E7EB（边框/分割线）
  --gray-300: #D1D5DB（禁用态边框）
  --gray-400: #9CA3AF（占位文字）
  --gray-500: #6B7280（次要文字）
  --gray-600: #4B5563（正文文字）
  --gray-700: #374151（标题文字）
  --gray-800: #1F2937（深色标题）
  --gray-900: #111827（页面标题）

状态色：
  紧急/逾期：  #EF4444（红）
  警告/临近：  #F59E0B（黄/橙）
  正常/进行中：#10B981（绿）
  已完结：     #6B7280（灰）
  信息：       #3B82F6（蓝）
```

### 2.2 字体

```
字体栈：-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", 
        "Microsoft YaHei", sans-serif

字号阶梯：
  --text-xs:   12px（标签、徽章）
  --text-sm:   13px（表格内容、次要信息）
  --text-base: 14px（正文默认）
  --text-lg:   16px（卡片标题）
  --text-xl:   18px（页面副标题）
  --text-2xl:  24px（页面标题）
  --text-3xl:  32px（数字展示）

行高：
  --leading-tight:  1.25（标题）
  --leading-normal: 1.5（正文）
  --leading-relaxed: 1.75（长文本）

字重：
  --font-normal:  400
  --font-medium:  500（表格标题、强调）
  --font-semibold: 600（页面标题）
```

### 2.3 间距

```
基础单位：4px

间距阶梯：
  --space-1:  4px
  --space-2:  8px（紧凑间距）
  --space-3:  12px（组件内间距）
  --space-4:  16px（标准间距）
  --space-5:  20px
  --space-6:  24px（区块间距）
  --space-8:  32px（大区块间距）
  --space-10: 40px
  --space-12: 48px（页面边距）
```

### 2.4 圆角

```
--radius-sm:  4px（标签、小按钮）
--radius-md:  6px（卡片、输入框）
--radius-lg:  8px（弹窗、大卡片）
--radius-xl:  12px（模态框）
--radius-full: 9999px（头像、圆形按钮）
```

### 2.5 阴影

```
--shadow-sm:  0 1px 2px rgba(0,0,0,0.05)（卡片默认）
--shadow-md:  0 4px 6px rgba(0,0,0,0.07)（悬浮/下拉）
--shadow-lg:  0 10px 15px rgba(0,0,0,0.1)（弹窗）
--shadow-xl:  0 20px 25px rgba(0,0,0,0.1)（模态框）
```

- flex: 1，占满剩余空间

- 背景：var(--gray-50)

## 六、交互规范

### 6.1 操作反馈

| 操作 | 反馈 | 时长 |
|------|------|------|
| 保存成功 | 右上角 toast（绿色勾 + "已保存"）| 2s |
| 删除确认 | 模态框确认（红色按钮）| 等待操作 |
| 自动保存 | 标题栏显示 "已保存" + 时间 | 持续 |
