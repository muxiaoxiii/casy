# 日历颜色编码实现记录

> **日期**: 2026-08-18  
> **状态**: 已完成  
> **影响范围**: 前端日历视图

---

## 一、实现概述

日历视图增强了颜色编码功能，帮助律师快速识别不同类型和紧急程度的事件。

---

## 二、颜色编码规则

### 2.1 事件类型颜色

| 事件类型 | 颜色 | 说明 |
|---------|------|------|
| 开庭 | 红色 (#EF4444) | 硬性日程 |
| 口审 | 红色 (#EF4444) | 硬性日程 |
| 紧急期限 | 红色 (#EF4444) | 已逾期或当天到期 |
| 即将到期 | 琥珀色 (#F59E0B) | 3天内到期 |
| 正常期限 | 绿色 (#10B981) | 正常期限 |

### 2.2 案件类型颜色

| 案件类型 | 颜色 | 说明 |
|---------|------|------|
| 计算型 | 蓝色 (#3B82F6) | 民诉/行政 |
| 探索型 | 紫色 (#8B5CF6) | 无效 |
| 成长型 | 绿色 (#10B981) | 顾问 |

### 2.3 优先级规则

1. **硬性日程优先**: 开庭/口审始终显示为红色
2. **逾期次之**: 逾期任务显示为红色
3. **即将到期**: 3天内到期显示为琥珀色
4. **案件类型**: 其他事件按案件类型着色

---

## 三、日期格子状态

### 3.1 状态指示器

| 状态 | 视觉表现 | 说明 |
|------|---------|------|
| 硬性日程 | 红色顶部边框 + 铃铛图标 | 当天有开庭/口审 |
| 逾期 | 琥珀色顶部边框 + 警告图标 | 当天有逾期任务 |
| 即将到期 | 无特殊边框 | 当天有3天内到期任务 |
| 今天 | 蓝色背景 | 当前日期 |
| 选中 | 蓝色边框 | 用户选中的日期 |

### 3.2 事件显示

- 硬性日程: 最多显示2个
- 期限: 最多显示1个
- 任务: 最多显示2个
- 更多: 显示 "+N" 提示

---

## 四、选中日期详情

### 4.1 面板内容

**统计信息**:
- 硬性日程数（红色）
- 期限数（琥珀色）
- 任务数（蓝色）
- 逾期数（红色）

**事件列表**:
- 按类型分组显示
- 硬性日程
- 期限
- 任务

**交互**:
- 点击任务 → 跳转到任务编辑

### 4.2 空状态

当日期无事件时显示"当日无事件"

---

## 五、设计原则遵循

### 5.1 原则五：克制即优雅

- 颜色只表语义，不表装饰
- 信息密度优先
- 视觉克制

### 5.2 原则四：数据有限，视图无限

- 日历是案件/任务数据的聚合视图
- 颜色编码由字段推导
