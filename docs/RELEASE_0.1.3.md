## 休息日前工作提醒

入口调整为「添加休息日」，不再要求用户选择个人上班。已有个人上班数据仍显示且可移除。法定节假日、普通周末和个人休息日合并为排期休息安排，个人上班/法定补班优先消除对应休息标记的提醒影响。

休息前一天检查当天至连续休息结束期间的未完成任务、独立日程、待开庭和未完成期限；休息日当天检查当日工作。通知中心显示特别提醒并可跳转日历，同一事项每日最多一条，任务与时间块去重，完成/改期/移除休息安排后刷新撤下。引擎每 5 分钟检查，通知角标每 60 秒和打开面板时刷新；应用关闭期间不发送。提醒只在应用内，不自动联系外部服务，也不修改法律期限。

新增后端提醒回归两项通过：休息前/当天与重复检查、用户处理状态、完成/改期撤下，以及连续法定长假、开庭/期限、任务时间块去重和法定周末补班。

最终前端回归在并行编译下出现一次编辑器 5 秒超时（287 通过、1 超时）；白板与编辑器 17 项在降低负载后专项补跑全部通过。此前完整前端 288 项已通过。测试未改变业务断言。原生大目录已从 Vite 文件监听排除，避免开发预览扫描无关构建产物。
