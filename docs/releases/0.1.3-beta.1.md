Casy 0.1.3-beta.1 是生产验证阶段的测试版本，不是正式稳定版。

- Windows x64：下载 setup.exe，按当前用户安装，需要 Windows 10/11 与 WebView2（安装器缺失时会联网安装）。
- macOS Apple Silicon：下载 DMG，需要 macOS 26 或更新版本；本次不提供 Intel Mac 安装包。
- 两端均包含本地 OCR、版面分析、E5 嵌入模型、PDF 渲染器和 Zvec 运行库；完整离线模型会使安装包较大。
- 本次包含编辑器块操作、历史版本入口、保存与冲突保护、工具策略设置和跨模块交互一致性改进。

签名状态：Windows 未签名；macOS 为 ad-hoc 签名，尚未 Apple 公证。系统可能显示未知开发者提示。本版本不进入稳定版自动更新通道。请先备份资料，用副本进行 beta 验证。

自动化检查包括单元测试、运行库文件校验、嵌入与向量索引自检，以及合成样本文档 OCR/PDF 冒烟检查；不代表已经完成所有真实法律文书与设备环境的人工验收。

每个安装包附 SHA-256 校验和及构建元数据。
